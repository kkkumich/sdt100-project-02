## Запуск

Требуется JDK 21. В IntelliJ: открыть проект, выбрать JDK, отметить src как Sources Root. Каждая часть запускается своим main. Рабочая папка — корень этого проекта.

Из PowerShell:

```powershell
$sourceFiles = @(Get-ChildItem src -Recurse -Filter *.java | ForEach-Object FullName)
javac -encoding UTF-8 -d build @sourceFiles
java -cp build part1_syntax.Main
java -cp build part2_dialog.Main
```

## Как объяснить

Тип определяет допустимые значения и операции. int делится на int с отбрасыванием дробной части. После приведения одного операнда к double деление становится вещественным. Данные читаются целой строкой и затем разбираются: это предотвращает проблему остаточного перевода строки после nextInt.

## Возможные вопросы

- **Почему 17/5 равно 3?** Оба операнда целые. (double)17/5 даёт 3.4.
- **Чем char отличается от String?** char хранит одну UTF-16 кодовую единицу, String — последовательность.
- **Что возвращает indexOf, если символ не найден?** -1.
